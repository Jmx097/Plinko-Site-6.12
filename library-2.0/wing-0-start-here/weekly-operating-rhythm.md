This is the actual cadence behind the systems in this library — a working founder running outbound, delivery, and an agent stack solo, around a day job and a family. Not theory.

## The System

1. **Monday — Pipeline block (60–90 min).** Run the sourcing line (see Lead Sourcing Production Line): refresh the list, score it, gate it, load it. The weekly refresh works because buyer-activity filters refill weekly; running it on Monday means the machine works the list all week while you don't.
2. **Daily — Reply sweep (10–15 min, twice a day).** Triage replies (your agent pre-classifies; you approve). Positive replies get answered inside 4 working hours. Nothing else interrupts your day.
3. **Wednesday — Send-window check (5 min).** Mid-week is the highest-reply window; confirm campaigns are sending and deliverability alerts are quiet.
4. **Friday — Scoreboard review (30 min).** Pull the week's numbers against your frozen KPI definitions, snapshot them, pick ONE focus for next week. (Full ritual: The Weekly Review Ritual, Wing 4.)
5. **Saturday — Build block (2–4 hours).** The only time you build: new automations, copy variants, library pages, course work. Everything discovered during the week goes on the build list and waits for Saturday. This single rule is what stops "tinkering" from eating your margin.
6. **Monthly — Cost snapshot (15 min, last day of month).** Re-snapshot your tool costs. Append the new line; never overwrite history.

## Why the blocks are sacred

The failure mode for every solo operator is the same: build whenever inspiration hits, review numbers never, and let replies set the day's agenda. The rhythm inverts that. Production is scheduled, building is contained, and the scoreboard gets 30 minutes whether the week was good or bad.
