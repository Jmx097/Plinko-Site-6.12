## How to read this map

The campus is not a content library you browse. It's a 90-day build with one rule: **ship one win a week and document it.** Each phase ends with an artifact, not a feeling.

## Days 1–30 — Your AI Digital Employee

The flagship course. By Day 30 you have:

- 2–3 working automations on your most repeatable tasks
- 1 browser/research agent doing real lookups for you
- A human-in-the-loop gate on anything that touches a customer
- **The Day-30 ROI Snapshot** — before/after numbers from your Day-0 baseline

Win cadence: Week 1 = first automation (Green Belt). Week 2 = second automation + your first "this broke, here's the fix" post. Week 3 = browser agent. Week 4 = snapshot.

## Days 31–60 — Run one function end-to-end

Pick the function that feeds you: for most members that's revenue. Open **The Revenue Engine** wing and stand up the production line: an ICP with a signal layer, a sourcing line with a quality gate, one outbound playbook running on schedule, and a reply-handling spine so nothing leaks.

Artifact: a week of pipeline produced **on schedule, not on inspiration** — your sends, replies, and follow-ups all happened without you pushing each one by hand. That's Amber Belt territory.

## Days 61–90 — Run the operating layer

Now the business runs on numbers and your agents become employees:

- **The Scoreboard:** write your KPI Dictionary, freeze the definitions, run the Friday review for 4 straight weeks
- **The Agent Workforce:** write an Employee File for each agent you run — role, tools, approval gates, monthly cost, failure modes
- **Governance:** one incident runbook for "an agent did something weird"

Artifact: the **Day-90 Snapshot** — same format as Day 30, now covering a whole function. Red Belt is when the system runs a week without you in every step.

## Agents Attached

By Day 90 you'll have 3–5. The Hiring Plan (Wing 3) tells you which one to hire at which stage.
